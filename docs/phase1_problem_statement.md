# Phase 1 Deliverable — One-Page Problem Statement

> **Counterfactual Conversation Emulation for Medical AI Agents**
> Author: Oliver Liu · Last updated 2026-05-05
> Scope: tight one-pager. Long-form version with derivations: `docs/problem_statement_v2.md`.

---

## 1. Setting

We observe a dataset of historical clinical encounters

$$
\mathcal{D} \;=\; \{(x_i,\, a_i^{\mathrm{clin}},\, y_i)\}_{i=1}^{n}
$$

generated by an unknown clinician policy $\pi_b$. Our target policy $\pi_{\mathrm{agent}}$ is a medical AI agent we want to evaluate **without running a prospective trial**.

## 2. Estimand

$$
\boxed{\,V(\pi_{\mathrm{agent}}) \;=\; \mathbb{E}_{x \sim p(x)}\Big[\,\mathbb{E}_{a \sim \pi_{\mathrm{agent}}(\cdot\mid x)}\big[\, Y(x, a)\,\big]\Big]\,}
$$

We additionally report the **policy contrast** $\Delta = V(\pi_{\mathrm{agent}}) - V(\pi_b)$, with bootstrap and split-conformal CIs at $1-\alpha = 0.9$.

## 3. Three locked-in decisions

| # | Decision | Choice | Rationale |
|---|----------|--------|-----------|
| **D1** | **Action granularity** | The agent's **final output** = `assessment + plan` (one block per encounter), **not** turn-level | Outcome easiest to ground here; matches BIDMC/AMIE rubric design; turn-level OPE explodes the action space |
| **D2** | **Outcome definition** | Continuous **rubric score** $Y \in [0, 1]^4$ from a debate-judge LLM, **not** binary diagnosis accuracy | Continuous score gives variance for OPE; 4 axes (DDx accuracy / Mx safety / Mx practicality / Mx cost) match the AMIE-BIDMC mechanism story |
| **D3** | **Target population** | Encounters where a **clinician note exists** (i.e. $a_i^{\mathrm{clin}}$ observed) | Natural support for positivity — every $x$ in the population is one a clinician chose to write up; agent actions evaluated only inside this support |

## 4. Identification assumptions

For unbiased identification of $V(\pi_{\mathrm{agent}})$ from observational $\mathcal{D}$:

| # | Assumption | Concrete meaning |
|---|-----------|-----------------|
| **A1** | **Consistency** | $Y_i = Y(x_i, a_i^{\mathrm{clin}})$ — observed score equals the potential outcome under the action that was taken |
| **A2** | **Positivity / overlap** | $p_{\pi_b}(a \mid x) > 0$ wherever $\pi_{\mathrm{agent}}(a \mid x) > 0$ — every action the agent might take must have non-zero probability under the clinician |
| **A3** | **Exchangeability** | $\{Y(x, a) : \forall a\} \perp\!\!\!\perp A^{\mathrm{clin}} \mid X$ — clinician's choice independent of potential outcomes given $x$ |
| **A4** | **No anticipation** | Clinician's encounter $i$ behavior unaffected by whether $\pi_{\mathrm{agent}}$ is later evaluated against it (trivially holds: historical data) |
| **A5** | **No interference** | Encounter $i$'s outcome does not depend on actions in encounter $j \ne i$ (panel-management edge cases excluded) |

**Comments**:
- **A2 is the binding constraint** — natural-language actions rarely overlap exactly. Mitigated by **MIPS over CCE embedding (U3)** which only requires overlap in embedding space; diagnosed by ESS/$n > 0.10$ and DRE classifier AUC $< 0.90$.
- **A3 is heroic in medicine** — clinicians use unmeasured social cues. Not assumed to hold; instead, **U4 reports MSM bounds at $\Gamma \in \{1, 1.5, 2, 3\}$** so the headline survives moderate unmeasured confounding.

## 5. Notation table

| Symbol | Meaning | Type |
|--------|---------|------|
| $\mathcal{X}$ | Patient pre-decision context space | text |
| $\mathcal{A}$ | Action space — natural-language assessment + plan | text |
| $\pi_b$ | Behavior policy (clinician), implicit | conditional dist over $\mathcal{A} \mid x$ |
| $\pi_{\mathrm{agent}}$ | Target policy (AI agent), evaluable | conditional dist over $\mathcal{A} \mid x$ |
| $Y_k(x, a) \in [0, 1]$ | Potential outcome on rubric axis $k$ | $k \in$ {ddx_accuracy, mx_safety, mx_practicality, mx_cost} |
| $\bar Y(x, a) = \frac{1}{4}\sum_k Y_k$ | Scalar overall outcome | float |
| $V(\pi)$ | Policy value $= \mathbb{E}_{x}[\,\mathbb{E}_{a \sim \pi}[Y(x, a)]\,]$ | float |
| $\Delta = V(\pi_{\mathrm{agent}}) - V(\pi_b)$ | Policy contrast | float |
| $\phi : \mathcal{A} \to \mathbb{R}^d$ | Action embedding (CCE-trained, $d = 128$) | learned |
| $w(x, a) = \pi_{\mathrm{agent}}(a \mid x) / \pi_b(a \mid x)$ | Density ratio | scalar per encounter |
| $f(x, a) \approx \mathbb{E}[Y \mid X=x, A=a]$ | Outcome model (RandomForest) | regression |
| $\Gamma$ | MSM sensitivity parameter | $\Gamma \geq 1$ |
| $\alpha$ | Conformal miscoverage level | 0.10 |
